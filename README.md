# 📊 Student Grade Analyzer

A Python program that helps students analyze their grades, calculate weighted averages, and understand their academic performance.

## 🚀 Project Overview

**Student Grade Analyzer** is a beginner Python project designed to make grade analysis simple and interactive.

The program allows users to enter their subjects, coefficients, and grades, then generates a weighted average and a basic performance analysis.

This project was built as part of my journey in learning Python and developing practical programming projects.

## ✨ Features

* 📚 Add multiple subjects dynamically
* 🔢 Enter subject coefficients
* 📝 Enter grades from 0 to 20
* ⚖️ Calculate weighted averages
* 🏆 Identify the highest and lowest grades
* 📊 Classify overall performance
* 💡 Provide personalized study advice
* ✅ Validate grades and coefficients
* ❌ Handle invalid user input

## 🧠 How It Works

The program follows these steps:

1. Enter the student's name.
2. Choose the number of subjects.
3. Enter each subject name.
4. Enter the coefficient for each subject.
5. Enter the grade for each subject.
6. Calculate the weighted average.
7. Analyze the student's performance.
8. Display the results and personalized feedback.
