# 📊 Student Grade Analyzer

A Python-based student performance analysis tool that calculates weighted averages, analyzes grades, stores data, visualizes results, tracks academic progress, and provides personalized study insights through an interactive GUI.

## 🚀 Project Overview

**Student Grade Analyzer** is a Python project designed to help students understand and track their academic performance.

The project combines fundamental Python programming with data analysis, file handling, data visualization, GUI development, testing, and rule-based insights.

## ✨ Features

* 📚 Weighted average calculation using subject coefficients
* 📈 Student grade analysis
* 🏆 Highest and lowest grade detection
* 📊 Mean, median, highest, and lowest statistics
* 📝 Personalized advice for each subject
* 🔢 Subject ranking
* 💾 CSV data storage
* 📉 Student progress tracking
* 📊 Grade visualization with Matplotlib
* 📈 Previous vs. current average progress chart
* 🖥️ Interactive GUI using `ipywidgets`
* 💡 Rule-based smart insights
* 🧪 Automated basic testing
* ✅ Input validation and error handling

## 🧠 How It Works

The program allows the user to:

1. Enter their name.
2. Choose the number of subjects.
3. Enter a previous average.
4. Enter each subject, coefficient, and grade.
5. Calculate the weighted average.
6. Analyze individual subject performance.
7. Generate statistics and rankings.
8. Compare the current average with a previous average.
9. Display grade and progress visualizations.
10. Receive rule-based study recommendations.
11. Save the results to a CSV file.

## 📊 Example
